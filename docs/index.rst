hmd-lang-conformance
####################

The shared conformance vocabulary for NeuronSphere's persistence stack. NERD005
in ``hmd-entity-storage`` ports that stack to Go and holds the Go and Python
implementations to the same behavior; both are run against the nouns defined
here, which cover every ``hmd-meta-types`` attribute type, required and
optional.

- ``src/schemas/hmd_lang_conformance/``: the ``.hms`` schemas, the source of truth.
- ``src/python/hmd_lang_conformance/``: the Python package, generated by
  ``make docker-render`` and committed.
- ``docker/Dockerfile.ms-base-test``: ``hmd-ms-base-test`` with this vocabulary
  installed (``make conformance-image``), the service the conformance suites run
  against.
